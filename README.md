# 工厂原型 Factory Proto

一个用**原生 JavaScript + HTML5 Canvas** 实现的类《异星工厂》（Factorio）工厂自动化游戏，运行在浏览器中。零依赖、零构建，克隆即玩。

## 特性

- **无限世界**：32×32 区块按需确定性生成，矿脉随距离富集；已探索区块随存档持久化
- **完整物流链**：传送带 / 快速带 / 极速带、地下带、分流器（支持优先级）、机械臂（长臂 / 过滤 / 堆叠 / 堆叠过滤，另有烧煤驱动的**燃料机械臂**，无需电力、开局可用）
- **生产建筑**：热能/电采矿机、抽油机、石炉 / 钢炉 / 电炉、组装机 I/II/III、炼油厂、化工厂
- **电力系统**：抽水机 → 锅炉烧蒸汽 → 蒸汽机发电的全链路模拟，另有太阳能板 + 蓄电器（含昼夜周期）、应急被动电源，以及**核能发电**（铀矿→离心机→核燃料→反应堆→**导热管→热交换器**→高温蒸汽→汽轮机，对齐《异星工厂》核能标准链路，功率远超蒸汽机）；核反应堆燃尽的燃料留下**废燃料棒**，可在离心机再生成铀-238，闭合核燃料循环；锅炉/石炉/钢铁炉/车头/载具等烧燃料设备均可改用**固体燃料**（由石油气/轻油在化工厂压制，能量约为煤 4 倍，更耐用）；另有**电灯**在夜间通电照亮基地
- **流体系统**：水、蒸汽、原油、重油 / 轻油 / 石油气 / 润滑油 / **硫酸**，管道、地埋管、储液罐（3×3 大容量）；**硫磺 / 硫酸化工链**（石油气+水→硫磺→硫酸，用于电池、激光炮塔与卫星等）；**流体桶装系统（Barrel）**——研究「流体处理」后可用钢板造**空桶**，在组装机接好流体管道选桶装配方把流体灌入桶中（每桶 50 单位），满桶可经传送带 / 机械臂 / 物流机器人 / 火车运输，再选倒空配方把流体倒回管道，实现流体走物流链（对齐《异星工厂》Barrel system）
- **科技树**：红 / 绿 / 蓝 / 军事 / **紫（产能）/ 黄（实用）** 六种科学包，35 项科技（含无限科技），研究中心自动消耗；科技有**前置依赖树**（如电力工程需先自动化、火箭技术需先电子学+极速物流），未满足前置会锁定显示；支持**研究队列**（多科技自动排队研究）；无限科技含**机械臂容量**（重复研究提升堆叠机械臂单次抓取数量）与**采矿产能 / 科研速度**等
- **配方科技解锁**：手搓、组装机 / 化工厂 / 炼油厂 / 离心机配方按科技解锁，未研究对应科技时配方置灰锁定（如高级电路板需电子学、火箭部件需火箭技术）
- **军事防御**：机枪炮塔、石墙、敌人生成与进攻（可在设置中开关战斗）
- **污染系统**（对齐《异星工厂》生态机制）：采矿 / 冶炼 / 石油化工 / 烧煤发电会排放污染，污染达到阈值后激怒虫巢、触发虫群反扑；污染以红褐色云雾叠加在基地上空、小地图同步显示，虫巢被激怒时变红泛光脉动。敌人会主动攻击基地建筑（建筑有耐久度，受损可修复，HP 归零被摧毁并掉落物资）；远程虫群与近战虫群都会破坏基地
- **修理包 / 树木 / 木材**：世界中的树木可砍伐获得木材；手持修理包点击受损建筑可修复耐久度（对齐《异星工厂》Repair pack）；木箱 / 铁箱 / 钢箱三级储物箱递进
- **战斗体系（扩充）**：多种敌人（小虫/大虫/远程吐痰虫/蠕虫/重甲虫/喷火虫/巨型蠕虫/巨兽虫/巨兽甲虫/巨兽吐痰虫/巨兽蠕虫）、玩家武器（手枪/冲锋枪/散弹枪/战斗散弹枪/火箭筒/火焰喷射器/手雷/集束手雷）、激光炮塔与火焰炮塔、玩家生命值与阵亡重生；敌人从可摧毁的**虫巢（Spawner）**附近生成。散弹枪系弹药分体系：散弹枪弹 / 穿甲散弹枪弹
- **敌人进化度系统**：敌人随游戏时间与击杀数不断**进化**（对齐《异星工厂》Evolution factor），进化度越高刷出的敌人越强、越容易出现高级变种，HUD 实时显示进化度百分比；进化度 0.9 后解锁**巨兽级（Behemoth）**敌人（巨兽甲虫/巨兽吐痰虫/巨兽蠕虫，属性最强）
- **巢穴进攻波次**：虫巢会周期性地集结成**建制进攻波**直扑基地（对齐《异星工厂》虫群波次），波次间隔随进化度与「高级战斗」科技缩短、规模与强度随进化度提升，警示 HUD 播报 + 号角警报音效
- **战斗机器人胶囊**：防御 / 干扰 / 破坏三种机器人胶囊，投掷后释放战斗机器人伴随玩家作战（跟随攻击 / 原地吸引火力 / 主动追杀敌人），有续航时间
- **区域力场胶囊**：毒胶囊（落地释放剧毒云雾，对范围内敌人持续伤害）、减速胶囊（落地形成减速力场，大幅降低范围内敌人与玩家的移动速度），对齐《异星工厂》Poison/Slowdown capsule
- **地面火焰残留（燃烧火场）**：火焰炮塔/火焰喷射器/喷火虫/巨型蠕虫火球命中地面后留下燃烧火场（对齐《异星工厂》Fire entity），火场内敌人与玩家持续受灼烧伤害，数秒后火焰自然熄灭；火焰呈橙色摇曳、随生命周期渐弱，带燃烧噼啪音效
- **终局铀系弹药**：铀弹（铀-238+穿甲弹，供冲锋枪与机枪炮塔，威力远超穿甲弹）、铀炮弹（供坦克主炮，范围爆炸威力更高），对齐《异星工厂》Uranium rounds / Uranium cannon shell
- **火焰弹药**：火焰喷射器改为消耗专用火焰弹药（由化工厂用轻油+重油制成，对齐《异星工厂》Flamethrower ammo），不再直接烧石油气
- **敌人掉落（Loot）**：击杀敌人/摧毁虫巢会掉落少量矿石（铁矿/铜矿/煤/石头，虫巢有一定概率掉铀矿），靠近自动拾取（对齐《异星工厂》击杀虫群掉落矿石）；**手雷**可在背包面板中直接「💣 投掷」，向当前朝向投出造成范围爆炸
- **模块系统**：速度 / 产能 / 效率模块各分 **1-3 级**（对齐《异星工厂》Module tiers），效果逐级增强，可装入组装机，加速生产、累积免费额外产出或大幅降低耗电；另有**信号塔 Beacon**（3×3）把模块效果广播给 9×9 范围内的多台生产建筑，一座信号塔服务整片产线
- **终局胜利**：火箭发射井分两阶段组装并发射（对齐《异星工厂》火箭流程）——① 集齐火箭燃料 / 控制单元 / 低密度结构，在井内组装出完整火箭本体；② 放入卫星后点击发射，倒计时成功后赢得游戏
- **物流机器人网络**：机器人港 + 五类物流箱（被动供应 / 主动供应 / 仓储 / 需求 / 缓冲）+ 物流机器人自动搬运，机器人回港充电（消耗电力）；缓冲箱兼具“请求 + 供应”能力，作为中转缓冲。另有**施工机器人 + 个人机器人港**——装备后蓝图粘贴生成建造幽灵、红图框选生成拆除标记，由施工机器人自动施工/拆除（消耗背包物资）
- **铁路系统**：铁轨铺设成网（自动连通可拐弯）、烧煤的火车头 + 货运车厢 / 流体车厢组成列车、**铁路信号灯 + 铁路链式信号灯**防追尾（链式信号灯连锁转发前方区段状态、强制更大的跟车距离，防止列车在复杂交叉口内停车堵塞，对齐《异星工厂》Rail chain signal）；**车站（Train Stop）可配置装载/卸载物品清单，列车停靠时自动从站旁储物箱装卸货**（对齐《异星工厂》火车自动化物流）；**火车自动调度路线（Schedule）**——给车站重命名后，在车头面板把多个车站按顺序加入路线，列车即沿铁轨循环往返各站自动装卸，实现两站/多站间往返自动化运输（对齐《异星工厂》Automatic Train Schedule）；流体车厢可运输任意一种流体（容量 2500）；**炮兵车厢（Artillery wagon）**——把炮兵炮台改装上车，列车行驶/停靠期间自动轰击极远距离的敌人，内装炮兵炮弹，让火车兼具移动炮兵阵地（对齐《异星工厂》Artillery wagon）；润滑油流体用于电动引擎等高级配方
- **重型坦克（Tank）**：装甲更厚的战斗载具，主炮发射炮弹造成范围爆炸伤害；需高级战斗科技
- **蜘蛛机器人（Spidertron）**：终极战斗载具——速度快、可跨越水域与石墙，车载自动炮塔自动攻击附近敌人，主炮发射导弹造成范围爆炸；需高级战斗科技
- **地雷（Landmine）**：铺设在地面，敌人踏入即爆炸造成范围伤害并自行销毁，玩家自身可安全通过
- **炮兵连（Artillery）**：超远程炮台，消耗炮弹轰击视野极远处的敌人，命中引发超大范围爆炸，晚期基地防御的利器；也可把炮兵炮台改装成**炮兵车厢**挂在火车上，列车沿途自动轰击远处敌人
- **护甲系统**：轻型 / 重型护甲可减少所受伤害（背包装备 / 脱卸），驾驶坦克时另有额外减伤
- **模块化护甲与个人装备网格**：模块化护甲 / 强力装甲 / 强力装甲 II 自带**装备网格**（5×5 / 7×7 / 8×8），可安装**个人装备件**——个人太阳能板（Ⅰ/Ⅱ，白天发电）、便携聚变反应堆（全天大功率）、个人电池（Ⅰ/Ⅱ，储电）、外骨骼（+40% 移动速度，可叠加）、夜视仪（夜间如白昼）、个人激光防御（自动攻击近身敌人，耗个人电力）、**能量护盾（Ⅰ/Ⅱ，受击时优先消耗个人电网电力生成护盾吸收伤害，并环绕淡蓝能量护罩）**；个人电网为这些装备供能，全流程存档持久化；另有**个人机器人港 II**（比 I 型工作范围更大、可同时调度更多施工机器人，对齐《异星工厂》Personal roboport Mk2）
- **钓鱼与生鱼**：靠近水域点击/轻触水面即可抛竿钓鱼，随机钓得生鱼，可作低效燃料；也可在背包中**食用回血**（恢复 20 生命值，对齐《异星工厂》吃鱼治疗）
- **研究队列**：可在科技面板把多个科技加入研究队列，研究中心按顺序自动研究，完成一项顺延下一项
- **雷达 & 小地图**：雷达周期性扫描周围区域、预生成新探索区块；右下角小地图（M 键切换）实时显示已探索地形 / 矿脉 / 玩家位置，助力基地扩张与远行导航
- **手搓合成队列**：手搓不再瞬时完成，而是按配方耗时逐件制作（背包显示进度、可连点排队、✕ 取消返还材料）
- **载具**：装甲车（Car）可驾驶——靠近按 E / F 进入，WASD 更快移动、消耗煤作燃料，E 下车
- **电路网络**：电线杆（小/中/大）自动连线组网，常量 / 运算 / 判断三种组合器处理信号（加减乘除、条件判断、红绿双通道）；流体泵、**机械臂**与**传送带**均可设电路启用条件实现信号启停（如铁板信号 ≥ 100 才送带 / 才取货）；另有覆盖范围超大的**变电站**（4×4）与可按条件触发告警的**可编程音箱**、可用电路信号控制全图断电的**功率开关**（Power Switch，甩负荷保护）
- **混凝土与地形改造**：铺设混凝土 / 石砖路加速玩家行走；**精炼混凝土**（比普通混凝土更快，对齐《异星工厂》Refined concrete）与**警示混凝土**（黑黄条纹装饰地砖）进一步丰富地面铺设；填海料把水面填成可建造陆地
- **蓝图系统**：蓝图框选复制 / 旋转 / 翻转 / 粘贴，红图拆除，绿图升级降级；装备个人机器人港后蓝图/红图改由施工机器人自动施工与拆除
- **防御与中间件**：新增**门 Gate**（玩家靠近自动开合、敌人无法通过）；**铁杆 / 钢杆** 中间件用于分流器、地下带、铁轨等配方
- **统计面板**：物品生产/消耗速率、电网发电/耗电明细、性能监控（P 键）；物品生产/消耗历史折线图（最近 24 小时，1 分钟粒度，随存档保存）
- **核能系统**：铀矿/离心机（含 Kovarex 富集）/核反应堆（并排相邻加成 +100%）/**导热管（Heat pipe）与热交换器（Heat exchanger）**/汽轮机/废燃料再生闭合循环——反应堆产热经导热管传导，由热交换器把水烧成高温蒸汽供汽轮机（对齐《异星工厂》反应堆→热交换器→汽轮机的标准核能链路）
- **空间科学包**：卫星发射成功获得空间科学包，用于终局无限科研（空间科研速度 / 空间采矿产能）
- **移动端适配**：全新触屏手势引擎——点按建造/开面板/点击移动、长按建筑弹径向操作盘（旋转/拆除/复制/拿起）、单指拖动平移视角、双指擡合缩放、双击旋转/回中；另保留虚拟摇杆与触屏拆除模式作为辅助
- **程序化音效（Web Audio）**：零依赖实时合成《异星工厂》风工业音效——建造/拆除、维修、手搓合成、科研完成、采矿、射击/霰弹/机枪/激光/火焰、爆炸、火箭发射与胜利号角、拒绝错误音、UI 点击与物品选中等；新增火车鸣笛、车辆引擎、虫群进攻波次号角、投掷物部署等环境音。并补充**物品拾取、模块安装、火箭部件装配、蓝图粘贴、施工机器人建成、炮兵开火、地雷引爆、流体泵、锅炉蒸汽、机械臂运转、物流机器人飞行、链式信号灯、地面火焰燃烧噼啪、玩家脚步、组装机/采矿机低频运转、坦克重炮**等音效。设置面板可一键开关音效并调节音量（默认开启，音量 80%）
- **工业粒子氛围（画面优化）**：零依赖轻量粒子系统——石炉/钢炉燃烧冒橙烟与火星、电炉冒淡绿烟、采矿机扬尘、化工厂/锅炉/核反应堆冒蒸汽并迸光星，随设备工作实时生成、缓慢上飘渐隐，增强工业氛围（低开销，不影响性能）
- **矿脉视觉增强（画面优化）**：矿点增加淡淡底色与矿物高光，原油油池增加反光，让矿脉更醒目、更具“富矿感”
- **昼夜环境音（氛围优化）**：游戏过程中叠加一层极低音量的**程序化环境背景音**——白昼是轻柔的工业嗡鸣与偶尔鸟鸣，夜晚转为静谧的虫鸣与低缓风声，随昼夜周期平滑过渡，让基地更有身临其境的氛围（受音效开关与音量控制，低开销）
- **动态水面（画面优化）**：水域叠加缓慢漂移的高光波纹，营造水流涌动的质感，低开销（不写入离屏缓存、不破坏分块缓存复用）
- **光影氛围（画面优化）**：激光采用“亮白核心 + 红晕辉光”的加法混合渲染、爆炸升级为“层次火球 + 冲击波扩散环”的动态辉光；昼夜切换叠加环境色温（黄昏/黎明暖橙、深夜冷蓝），让日夜转换更有层次感

## 运行

无需安装任何依赖，用任意静态服务器托管根目录即可：

```bash
# Python
python -m http.server 8000

# Node
npx serve .
```

然后访问 `http://localhost:8000`。

> 直接双击 `index.html` 也能游玩（IndexedDB 在 `file://` 下部分浏览器受限，推荐走本地服务器）。


## 上手流程

1. 手挖一些石头 → 合成石炉和热能采矿机，烧出铁板 / 铜板
2. 铺设采矿机 + 传送带 + 机械臂 + 组装机，实现自动化产铁齿轮、电路板
3. 研究中心放上自动化科学包（红瓶），推进首批科技
4. 抽水机供水 → 锅炉烧煤产蒸汽 → 蒸汽机发电，解锁电炉、电采矿机与组装机 II
5. 绿瓶解锁石油冶金：抽油机采原油 → 炼油厂裂化 → 化工厂产塑料 → 蓝色科学包
6. 军事工程解锁炮塔与石墙，抵御周期性刷出的敌人
7. 用蓝图批量复制产线，冲向极速物流与无限科技
8. 蓝瓶研究「物流网络」，建机器人港与供应/需求箱，用物流机器人实现自动化原料配送；研究「高级战斗」后可造坦克、重型护甲与激光/火焰炮塔，应对更强敌人
9. 研究「铁路技术」，铺设铁轨 + 烧煤车头拉货，用车站构建跨区域长途物流；化工厂用重油产出润滑油供电动引擎
10. 研究「塑料合成」后，用化工厂把石油气/轻油压制成**固体燃料**，作为更高能的燃料替换煤，并用于制造火箭燃料；冲击火箭技术，造出火箭发射井与卫星，发射火箭赢得游戏
11. 研究「产能科技」解锁**紫瓶（产能科学包）与信号塔 Beacon**，用信号塔把模块加成广播给大片产线；研究「实用科技」解锁**黄瓶（实用科学包）、飞行机器人框架与施工机器人**，装备个人机器人港后蓝图自动施工、红图自动拆除
12. 铺**铁杆/钢杆**生产链（分流器、地下带、铁轨等都用到），研究**采矿产能 / 机器人速度 / 科研速度**等紫黄瓶终技，把产能推向极限

## 触屏操作（全新手势系统）

触屏设备不再依赖“模式切换”，一切操作通过直觉手势完成，无需反复进出建造/拆除模式：

| 手势 | 作用 |
| --- | --- |
| 点按 | 有选中物品→就地建造；无选中→点建筑开面板 / 点矿石挖一格 / 点空地走过去 |
| 长按建筑 | 弹出径向“操作盘”：打开 / 旋转 / 复制配置 / 拿起物品 / 拆除 |
| 长按矿石 | 连续采集（按住不放） |
| 单指拖动 | 空闲时平移视角；选中物品时沿途铺设（拖动连建带线） |
| 双指擡合 | 缩放视野（取代滚轮） |
| 双击 | 双击建筑→旋转；双击空地→旋转放置朝向 / 相机回中；双击矿石→挖两格 |

> 原有虚拟摇杆与“✖ 拆除”模式仍保留在设置中，作为辅助手段可选使用。

## 代码结构

```
index.html          入口页面，按依赖顺序加载全部脚本（无打包器）
css/style.css       全部样式
js/
├── data.js         常量与数据表：物品、配方、功率数值、科技树、物品图标绘制
├── world.js        无限分块世界：确定性地形/矿脉生成、区块编解码持久化
├── main.js         游戏主循环 G 全局状态、输入处理、建造/拆除逻辑
├── player.js       玩家角色：移动、碰撞、背包、手挖
├── ui.js           HUD、快捷栏、背包、面板、提示、设置、摇杆
├── menu.js         开始菜单（新游戏 / 读档）
├── render.js       相机与渲染调度、地形分块离屏缓存
├── stats.js        生产/电力/性能统计面板
├── saves.js        IndexedDB 多存档系统（自动存档 + 用户存档 + 旧版迁移）
├── sfx.js          程序化音效引擎（Web Audio API 实时合成，零外部音频文件）
├── touch.js        全新触屏手势引擎（点按/长按操作盘/拖动平移/擡合缩放/双击）
├── core/
│   ├── registry.js 设备类型注册表
│   ├── entity.js   Entity 基类与空间索引（分桶 Set）
│   ├── draw.js     通用绘制工具
│   └── power.js    电网增量计算（只扫描发电/耗电子集）
└── devices/        每种设备一个文件：belt、inserter、assembler、boiler…
```

架构要点：

- **无框架无依赖**：全局单例 `G` 承载状态，各模块以普通脚本顺序加载共享作用域
- **设备插件式**：新设备只需在 `js/devices/` 新建文件，向注册表登记类型、实现 `update` 与绘制函数，再在 `index.html` 引入
- **确定性世界**：地形由种子哈希即时重建，只有"被开采过"的矿量差值需要存档
- **缓存友好**：地形分块预渲染到离屏 canvas；实体按桶空间索引；电网维护增量注册表避免全量遍历

## 开发

- 修改任意 JS/CSS 后刷新浏览器即可生效（脚本 URL 带 `?v=N` 版本号用于破缓存，改动后记得递增）
- 数值平衡集中在 `js/data.js` 顶部常量区（带速、功率、配方耗时均对齐 Factorio Wiki 数值）
