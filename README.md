# 工厂原型 Factory Proto

一个用**原生 JavaScript + HTML5 Canvas** 实现的类《异星工厂》（Factorio）工厂自动化游戏，运行在浏览器中。零依赖、零构建，克隆即玩。

## 特性

- **无限世界**：32×32 区块按需确定性生成，矿脉随距离富集；已探索区块随存档持久化
- **完整物流链**：传送带 / 快速带 / 极速带、地下带、分流器（支持优先级）、机械臂（长臂 / 过滤 / 堆叠 / 堆叠过滤）
- **生产建筑**：热能/电采矿机、抽油机、石炉 / 钢炉 / 电炉、组装机 I/II/III、炼油厂、化工厂
- **电力系统**：抽水机 → 锅炉烧蒸汽 → 蒸汽机发电的全链路模拟，另有太阳能板 + 蓄电器（含昼夜周期）、应急被动电源，以及**核能发电**（铀矿→离心机→核燃料→反应堆→汽轮机，功率远超蒸汽机）；锅炉/石炉/钢铁炉/车头/载具等烧燃料设备均可改用**固体燃料**（由石油气/轻油在化工厂压制，能量约为煤 4 倍，更耐用）
- **流体系统**：水、蒸汽、原油、重油 / 轻油 / 石油气 / 润滑油，管道、地埋管、储液罐（3×3 大容量）
- **科技树**：红 / 绿 / 蓝 / 军事四种科学包，23 项科技（含无限科技），研究中心自动消耗
- **军事防御**：机枪炮塔、石墙、敌人生成与进攻（可在设置中开关战斗）
- **战斗体系（扩充）**：多种敌人（小虫/大虫/远程吐痰虫/蠕虫）、玩家武器（手枪/冲锋枪/散弹枪/火箭筒/火焰喷射器/手雷）、激光炮塔与火焰炮塔、玩家生命值与阵亡重生；敌人从可摧毁的**虫巢（Spawner）**附近生成
- **战斗机器人胶囊**：防御 / 干扰 / 破坏三种机器人胶囊，投掷后释放战斗机器人伴随玩家作战（跟随攻击 / 原地吸引火力 / 主动追杀敌人），有续航时间
- **模块系统**：速度模块 / 产能模块 / 效率模块可装入组装机，加速生产、累积免费额外产出或大幅降低耗电
- **终局胜利**：火箭发射井 + 卫星发射火箭（火箭燃料 / 控制单元 / 低密度结构），倒计时发射成功后赢得游戏
- **物流机器人网络**：机器人港 + 四类物流箱（被动供应 / 主动供应 / 仓储 / 需求）+ 物流机器人自动搬运，机器人回港充电（消耗电力）
- **铁路系统**：铁轨铺设成网（自动连通可拐弯）、烧煤的火车头 + 货运车厢 / 流体车厢组成列车、车站自动装卸、铁路信号灯防追尾；流体车厢可运输任意一种流体（容量 2500）；润滑油流体用于电动引擎等高级配方
- **重型坦克（Tank）**：装甲更厚的战斗载具，主炮发射炮弹造成范围爆炸伤害；需高级战斗科技
- **护甲系统**：轻型 / 重型护甲可减少所受伤害（背包装备 / 脱卸），驾驶坦克时另有额外减伤
- **雷达 & 小地图**：雷达周期性扫描周围区域、预生成新探索区块；右下角小地图（M 键切换）实时显示已探索地形 / 矿脉 / 玩家位置，助力基地扩张与远行导航
- **手搓合成队列**：手搓不再瞬时完成，而是按配方耗时逐件制作（背包显示进度、可连点排队、✕ 取消返还材料）
- **载具**：装甲车（Car）可驾驶——靠近按 E / F 进入，WASD 更快移动、消耗煤作燃料，E 下车
- **电路网络**：电线杆（小/中/大）自动连线组网，常量 / 运算 / 判断三种组合器处理信号（加减乘除、条件判断、红绿双通道）；流体泵可设电路启用条件实现信号控制
- **混凝土与地形改造**：铺设混凝土 / 石砖路加速玩家行走；填海料把水面填成可建造陆地
- **蓝图系统**：蓝图框选复制 / 旋转 / 翻转 / 粘贴，红图拆除，绿图升级降级
- **统计面板**：物品生产/消耗速率、电网发电/耗电明细、性能监控（P 键）；物品生产/消耗历史折线图（最近 24 小时，1 分钟粒度，随存档保存）
- **多存档**：IndexedDB 存储，3 个自动存档槽轮换 + 最多 10 个用户命名存档（K 存 / L 读）
- **移动端适配**：全新触屏手势引擎——点按建造/开面板/点击移动、长按建筑弹径向操作盘（旋转/拆除/复制/拿起）、单指拖动平移视角、双指擡合缩放、双击旋转/回中；另保留虚拟摇杆与触屏拆除模式作为辅助

## 运行

无需安装任何依赖，用任意静态服务器托管根目录即可：

```bash
# Python
python -m http.server 8000

# Node
npx serve .
```

然后访问 `http://localhost:8000`。

> 直接双击 `index.html` 也能游玩（IndexedDB 在 `file://` 下部分浏览器受限，推荐走本地服务器）。


## 上手流程

1. 手挖一些石头 → 合成石炉和热能采矿机，烧出铁板 / 铜板
2. 铺设采矿机 + 传送带 + 机械臂 + 组装机，实现自动化产铁齿轮、电路板
3. 研究中心放上自动化科学包（红瓶），推进首批科技
4. 抽水机供水 → 锅炉烧煤产蒸汽 → 蒸汽机发电，解锁电炉、电采矿机与组装机 II
5. 绿瓶解锁石油冶金：抽油机采原油 → 炼油厂裂化 → 化工厂产塑料 → 蓝色科学包
6. 军事工程解锁炮塔与石墙，抵御周期性刷出的敌人
7. 用蓝图批量复制产线，冲向极速物流与无限科技
8. 蓝瓶研究「物流网络」，建机器人港与供应/需求箱，用物流机器人实现自动化原料配送；研究「高级战斗」后可造坦克、重型护甲与激光/火焰炮塔，应对更强敌人
9. 研究「铁路技术」，铺设铁轨 + 烧煤车头拉货，用车站构建跨区域长途物流；化工厂用重油产出润滑油供电动引擎
10. 研究「塑料合成」后，用化工厂把石油气/轻油压制成**固体燃料**，作为更高能的燃料替换煤，并用于制造火箭燃料；冲击火箭技术，造出火箭发射井与卫星，发射火箭赢得游戏

## 触屏操作（全新手势系统）

触屏设备不再依赖“模式切换”，一切操作通过直觉手势完成，无需反复进出建造/拆除模式：

| 手势 | 作用 |
| --- | --- |
| 点按 | 有选中物品→就地建造；无选中→点建筑开面板 / 点矿石挖一格 / 点空地走过去 |
| 长按建筑 | 弹出径向“操作盘”：打开 / 旋转 / 复制配置 / 拿起物品 / 拆除 |
| 长按矿石 | 连续采集（按住不放） |
| 单指拖动 | 空闲时平移视角；选中物品时沿途铺设（拖动连建带线） |
| 双指擡合 | 缩放视野（取代滚轮） |
| 双击 | 双击建筑→旋转；双击空地→旋转放置朝向 / 相机回中；双击矿石→挖两格 |

> 原有虚拟摇杆与“✖ 拆除”模式仍保留在设置中，作为辅助手段可选使用。

## 代码结构

```
index.html          入口页面，按依赖顺序加载全部脚本（无打包器）
css/style.css       全部样式
js/
├── data.js         常量与数据表：物品、配方、功率数值、科技树、物品图标绘制
├── world.js        无限分块世界：确定性地形/矿脉生成、区块编解码持久化
├── main.js         游戏主循环 G 全局状态、输入处理、建造/拆除逻辑
├── player.js       玩家角色：移动、碰撞、背包、手挖
├── ui.js           HUD、快捷栏、背包、面板、提示、设置、摇杆
├── menu.js         开始菜单（新游戏 / 读档）
├── render.js       相机与渲染调度、地形分块离屏缓存
├── stats.js        生产/电力/性能统计面板
├── saves.js        IndexedDB 多存档系统（自动存档 + 用户存档 + 旧版迁移）
├── touch.js        全新触屏手势引擎（点按/长按操作盘/拖动平移/擡合缩放/双击）
├── core/
│   ├── registry.js 设备类型注册表
│   ├── entity.js   Entity 基类与空间索引（分桶 Set）
│   ├── draw.js     通用绘制工具
│   └── power.js    电网增量计算（只扫描发电/耗电子集）
└── devices/        每种设备一个文件：belt、inserter、assembler、boiler…
```

架构要点：

- **无框架无依赖**：全局单例 `G` 承载状态，各模块以普通脚本顺序加载共享作用域
- **设备插件式**：新设备只需在 `js/devices/` 新建文件，向注册表登记类型、实现 `update` 与绘制函数，再在 `index.html` 引入
- **确定性世界**：地形由种子哈希即时重建，只有"被开采过"的矿量差值需要存档
- **缓存友好**：地形分块预渲染到离屏 canvas；实体按桶空间索引；电网维护增量注册表避免全量遍历

## 开发

- 修改任意 JS/CSS 后刷新浏览器即可生效（脚本 URL 带 `?v=N` 版本号用于破缓存，改动后记得递增）
- 数值平衡集中在 `js/data.js` 顶部常量区（带速、功率、配方耗时均对齐 Factorio Wiki 数值）
