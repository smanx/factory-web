# 工厂原型 Factory Proto

一个用**原生 JavaScript + HTML5 Canvas** 实现的类《异星工厂》（Factorio）工厂自动化游戏，运行在浏览器中。零依赖、零构建，克隆即玩。

## 特性

- **无限世界**：32×32 区块按需确定性生成，矿脉随距离富集；已探索区块随存档持久化；矿脉储量有限、会逐渐采空（对齐《异星工厂》矿脉枯竭），采矿机悬浮提示与面板会实时显示矿脉剩余储量、并在即将采空时预警，便于规划迁移产线。**地图生成器配置（对齐《异星工厂》新游戏地图设置）**：开始新游戏前可定制世界参数——**世界种子**（相同种子生成相同世界，可输入或随机）、**地图大小**（小/中/大/无限，有限地图外为不可通行的海域边界）、**资源丰富度 / 频率 / 大小**（低/中/高，分别调节矿量、矿团数量与尺寸）、**水频率**（低/中/高）、**峭壁**（开启/关闭，是否生成峭壁山脊）、**敌人**（**无** = 完全没有敌人 / **和平** = 敌人存在但只在虫巢周围游荡、永不主动攻击 / 低 / 中 / 高，高难度开局自带初始进化度且刷怪更密集）；配置随存档持久化，读档后世界保持一致
- **完整物流链**：传送带 / 快速带 / 极速带、地下带、分流器（普通 / **快速** / 极速三级分级，支持优先级与**可编程分离器过滤**——所有分流器均可设面板指定仅放行某一种物品，其余物品被挡在入口，对齐《异星工厂》Programmable splitter）、机械臂（**快速** / 长臂 / 过滤 / 堆叠 / 堆叠过滤，另有烧煤驱动的**燃料机械臂**，无需电力、开局可用；其中**快速机械臂**旋转速度约为普通臂 2 倍，对齐《异星工厂》Fast inserter）；**传送带会推动站在上面的玩家**（对齐《异星工厂》物理机制），穿戴「传送带免疫」装备可站定不动
- **生产建筑**：热能/电采矿机、抽油机、石炉 / 钢炉 / 电炉、组装机 I/II/III、炼油厂、化工厂
- **电力系统**：抽水机 → 锅炉烧蒸汽 → 蒸汽机发电的全链路模拟，另有太阳能板 + 蓄电器（含昼夜周期）、应急被动电源，以及**核能发电**（铀矿→离心机→核燃料→反应堆→**导热管→热交换器**→高温蒸汽→汽轮机，对齐《异星工厂》核能标准链路，功率远超蒸汽机）；核反应堆燃尽的燃料留下**废燃料棒**，可在离心机再生成铀-238，闭合核燃料循环；锅炉/石炉/钢铁炉/车头/载具等烧燃料设备均可改用**固体燃料**（由石油气/轻油/重油在化工厂压制——三种原油产物均可压制，对齐《异星工厂》三种固体燃料配方，能量约为煤 4 倍，更耐用）；研究火箭技术后，**火箭燃料**（由固体燃料+轻油+电引擎制成）成为能量最高的可燃烧燃料（约为固体燃料 10 倍、煤 40 倍），可投入锅炉/熔炉/采矿机/火车/载具燃烧，且所有烧燃料设备**自动优先消耗更高能量的燃料**（核燃料 > 火箭燃料 > 固体燃料 > 煤 > 木材，对齐《异星工厂》燃料分级）；其中**木材**由砍树所得，可作低效燃料（能量约为煤的 1/4，最后烧），对齐《异星工厂》：原木可直接当燃料；研究核能后由铀-235制成的**核燃料**（能量约为火箭燃料 5 倍）更可作载具 / 车头 / 锅炉等的**最高级燃料**（对齐《异星工厂》Nuclear fuel 为终极燃烧燃料）；另有**电灯**在夜间通电照亮基地
- **流体系统**：水、蒸汽、原油、重油 / 轻油 / 石油气 / 润滑油 / **硫酸**，管道、地埋管、储液罐（3×3 大容量，**储液罐已接入电路网络**——罐内流体存量以该流体名（如水→water）作为信号输出到所连网络，供组合器/功率开关/机械臂等做按液位自动化调度，对齐《异星工厂》Storage tank 电路信号）；**抽油机油井产量递减**（每口油井随抽取逐渐减产，最低降到原始值的 20%，越抽越慢，对齐《异星工厂》Oil well depletion，需开新井补充）；**硫磺 / 硫酸化工链**（石油气+水→硫磺→硫酸，用于电池、激光炮塔与卫星等）；**流体桶装系统（Barrel）**——研究「流体处理」后可用钢板造**空桶**，在组装机接好流体管道选桶装配方把流体灌入桶中（每桶 50 单位），满桶可经传送带 / 机械臂 / 物流机器人 / 火车运输，再选倒空配方把流体倒回管道，实现流体走物流链（对齐《异星工厂》Barrel system）
- **科技树**：红 / 绿 / 蓝 / 军事 / **紫（产能）/ 黄（实用）** 六种科学包，70 项科技（含无限科技），研究中心自动消耗；科技有**前置依赖树**（如电力工程需先自动化、火箭技术需先电子学+极速物流），未满足前置会锁定显示；支持**研究队列**（多科技自动排队研究）；无限科技含**机械臂容量**（重复研究提升堆叠机械臂单次抓取数量）、**追随机器人**（提升战斗机器人同时在场数量上限，对齐《异星工厂》Follower robot count）、**武器伤害**（每级 +10% 全武器与炮塔伤害，对齐《异星工厂》Weapon damage 无限科技）、**机器人容量**（每级提升物流机器人单次搬运量 +2，对齐《异星工厂》Worker robot cargo size）、**炮兵射速**（每级提升炮兵连/炮兵车厢射击速度 +10%，对齐《异星工厂》Artillery shell shooting speed）等；并已把**机器人速度 / 科研速度 / 采矿产能**升级为可重复研究的无限科技（对齐异星工厂同名无限科技：首次研究解锁前置、后续无限叠加等级）；**空间科研速度 / 空间采矿产能**无限科技（火箭发射后用空间科学包推进）已接入实际效果，随等级分别加速科研与采矿；**燃料效率**无限科技（对齐《异星工厂》Fuel efficiency）——每次研究降低锅炉 / 熔炉 / 矿机 / 燃料机械臂 / 车头 / 载具等所有燃烧设备的燃料消耗约 9%，让每单位煤 / 固体燃料 / 火箭燃料更耐用，终局燃料链条更经济（核燃料棒不受影响，对齐原版）；**研究中心可装产能/速度/效率模块**，产能模块让部分科研免费（减少科学包消耗，对齐《异星工厂》Lab productivity modules）。**补齐原版基础科技（对齐《异星工厂》科技树颗粒度）**：**太阳能**（解锁太阳能板，蓝瓶）、**蓄电器**（解锁蓄电器，蓝瓶，需太阳能前置）、**炼钢科技**（解锁钢炉/钢箱）、**地下管道**（解锁地下管道与流体泵，绿瓶油料科技）、**战斗机器人**（解锁防御/干扰/破坏三种战斗机器人胶囊）；这些物品此前开局即可用，现改为对应科技解锁，让生产/电力/物流节奏更贴近原版进阶曲线，旧存档经迁移自动补完对应科技。**补齐原版进阶电子/流体科技细分（对齐《异星工厂》Advanced electronics / Sulfur processing）**：把高级电路板、处理器、电动引擎与硫磺/硫酸从「电子学」「石油冶金」中拆分为独立进阶科技——**高级电子学**（蓝瓶，解锁高级电路板）、**高级电子学 II**（蓝瓶，解锁处理器，需高级电子学+进阶原油加工前置）、**电动引擎**（蓝瓶，解锁电动引擎，需引擎技术+高级电子学前置）、**硫磺处理**（蓝瓶，解锁硫磺与硫酸，需石油冶金前置），让中后期电子/流体进阶节奏更贴近原版科技树，旧存档经迁移自动补完对应科技（兼容任一科技解锁）。**进阶物流/自动化科技（对齐原版 Logistics 3 / Automation 3）**：新增**物流 III**（绿+蓝瓶，解锁堆叠机械臂 / 堆叠过滤机械臂）与**自动化 III**（蓝瓶+绿瓶，解锁组装机 III）——这两类此前开局即可用，现改为对应科技解锁，旧存档经迁移自动补完。**进阶材料处理（对齐原版 Advanced material processing）**：新增**进阶材料处理 I/II/III** 科技链独立解锁效率模块 I/II/III（对齐原版：效率模块由进阶材料处理科技解锁），旧档已研究「模块工程」的玩家不受影响（兼容任一科技解锁）。**炮兵射程无限科技**：新增**炮兵射程**（每级提升炮兵连/炮兵车厢射程 +30%，对齐《异星工厂》Artillery shell range）。**铁路产能无限科技**：新增**铁路产能**（每次研究提升货运车厢槽位容量 +2，让列车单趟装载更多货物，对齐《异星工厂》Rail productivity）。新增**火车制动**无限科技（每次研究缩短列车停靠与信号灯让行等待 15%，提升铁路吞吐，对齐《异星工厂》Braking force）与**火箭产能**科技（逐级降低火箭组装所需的火箭燃料与低密度结构数量，让终局火箭冲刺更轻松，对齐《异星工厂》Rocket productivity）。另新增**军事科技 III / IV**（对齐原版 Military 3 / Military 4，逐级强化机枪炮塔伤害）。**补齐原版基础中间件科技门控（对齐原版科技树颗粒度）**：新增**引擎技术**（绿瓶，解锁引擎单元——载具/电动引擎/重型机械的核心部件，对齐原版 Engine）与**电池技术**（蓝瓶，解锁电池——激光炮塔/卫星/机器人的核心原料，对齐原版 Battery）；并把**塑料板**（→ 塑料合成）、**低密度结构**（→ 火箭技术）、**固体燃料**（→ 石油冶金）纳入对应科技解锁，让生产节奏更贴近原版进阶曲线，旧存档经迁移自动补完对应科技。
**补齐原版军事无限科技（对齐《异星工厂》Military research）**：**投射物伤害**（枪械/子弹/车辆机炮，每级 +10%）、**能量武器伤害**（激光炮塔/个人激光防御）、**燃烧伤害**（火焰喷射器/火焰炮塔/地面火场）、**爆炸伤害**（火箭筒/炮弹/手雷/炮兵/地雷/原子弹），四者在通用「武器伤害」之上按武器类别再叠加，终局军备成长更细分。另新增**射击速度**无限科技（对齐《异星工厂》Shooting speed）：每次研究提升玩家枪械（手枪/冲锋枪/散弹枪/战斗散弹枪）、机枪炮塔与装甲车车载机枪的射击速度（射击间隔缩短 10%），让枪械在终局也能随科技持续强化，与伤害科技形成「伤害+射速」双维军备成长。
**进阶科技拆分（对齐原版科技树颗粒度）**：把原本直接可用/仅按核能门控的配方拆成独立进阶科技——**进阶原油加工**（解锁进阶原油加工与重/轻油裂化）、**煤液化**（解锁煤液化配方，缺油时用煤产油）、**铀富集**（解锁 Kovarex 富集循环，铀-235 可自持增产）、**原子弹科技**（终极核武器独立科技，需核能+火箭基础上进阶研究）；未研究对应科技时对应配方在炼油厂/化工厂/离心机面板显示锁定；另新增**光学**（解锁雷达，对齐原版 Optics）、**军事科技 II**（解锁战斗散弹枪 / 火箭筒 / 穿甲散弹枪弹，对齐原版 Military 2）、**军事科技 III**（解锁坦克 / 炮弹 / 重型护甲，对齐原版 Military 3）、**军事科技 IV**（解锁蜘蛛机器人 / 炮兵系统，对齐原版 Military 4）、**激光炮塔**（解锁激光炮塔，对齐原版 Laser turret）、**火焰科技**（解锁火焰喷射器 / 火焰炮塔 / 火焰弹药，对齐原版 Flamethrower）、**地雷**（解锁地雷，对齐原版 Landmines）、**集束手雷**（解锁集束手雷，对齐原版 Cluster grenade）与**铀弹**（解锁铀弹 / 铀炮弹，对齐原版 Uranium ammo）独立科技节点，把高级战斗 / 军事 / 核能等合并科技细分为贴近原版科技树的研发节奏，激光炮塔与火焰武器从「高级战斗」中拆出、由各自科技独立解锁
- **配方科技解锁**：手搓、组装机 / 化工厂 / 炼油厂 / 离心机配方按科技解锁，未研究对应科技时配方置灰锁定（如高级电路板需高级电子学、处理器需高级电子学 II、火箭部件需火箭技术）；**切换配方返还残留物料**——组装机 / 化工 / 炼油 / 离心机在切换或清除配方时，会把已投入但未消耗的原料与已产出成品返还到机器旁地面（流体推回相连管道），避免原料凭空丢失（对齐《异星工厂》：切换配方返还残留）

## 运行

无需安装任何依赖，用任意静态服务器托管根目录即可：

```bash
# Python
python -m http.server 8000

# Node
npx serve .
```

然后访问 `http://localhost:8000`。

> 直接双击 `index.html` 也能游玩（IndexedDB 在 `file://` 下部分浏览器受限，推荐走本地服务器）。


## 上手流程

0. **（可选）配置地图**：点「开始新游戏」前可先在地图设置面板定制世界——输入/随机种子、选择地图大小、资源与水频率、敌人强度，确认后开局（默认随机即可直接开始）
1. 手挖一些石头 → 合成石炉和热能采矿机，烧出铁板 / 铜板
2. 铺设采矿机 + 传送带 + 机械臂 + 组装机，实现自动化产铁齿轮、电路板
3. 研究中心放上自动化科学包（红瓶），推进首批科技
4. 抽水机供水 → 锅炉烧煤产蒸汽 → 蒸汽机发电，解锁电炉、电采矿机与组装机 II
5. 绿瓶解锁石油冶金：抽油机采原油 → 炼油厂裂化 → 化工厂产塑料 → 蓝色科学包
6. 军事工程解锁炮塔与石墙，抵御周期性刷出的敌人
7. 用蓝图批量复制产线，冲向极速物流与无限科技
8. 蓝瓶研究「物流网络」，建机器人港与供应/需求箱，用物流机器人实现自动化原料配送；研究「高级战斗」后可造坦克、重型护甲与激光/火焰炮塔，应对更强敌人
9. 研究「铁路技术」，铺设铁轨 + 烧煤车头拉货，用车站构建跨区域长途物流；化工厂用重油产出润滑油供电动引擎
10. 研究「塑料合成」后，用化工厂把石油气/轻油/重油压制成**固体燃料**，作为更高能的燃料替换煤，并用于制造火箭燃料；冲击火箭技术，造出火箭发射井与卫星，发射火箭赢得游戏
11. 研究「产能科技」解锁**紫瓶（产能科学包）与信号塔 Beacon**，用信号塔把模块加成广播给大片产线；研究「实用科技」解锁**黄瓶（实用科学包）、飞行机器人框架与施工机器人**，装备个人机器人港后蓝图自动施工、红图自动拆除
12. 铺**铁杆/钢杆**生产链（分流器、地下带、铁轨等都用到），研究**采矿产能 / 机器人速度 / 科研速度**等紫黄瓶终技，把产能推向极限


架构要点：

- **无框架无依赖**：全局单例 `G` 承载状态，各模块以普通脚本顺序加载共享作用域
- **设备插件式**：新设备只需在 `js/devices/` 新建文件，向注册表登记类型、实现 `update` 与绘制函数，再在 `index.html` 引入
- **确定性世界**：地形由种子哈希即时重建，只有"被开采过"的矿量差值需要存档
- **缓存友好**：地形分块预渲染到离屏 canvas；实体按桶空间索引；电网维护增量注册表避免全量遍历

## 开发

- 修改任意 JS/CSS 后刷新浏览器即可生效（脚本 URL 带 `?v=N` 版本号用于破缓存，改动后记得递增）
- 数值平衡集中在 `js/data.js` 顶部常量区（带速、功率、配方耗时均对齐 Factorio Wiki 数值）
